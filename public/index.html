Connect Any Client or SDK

Because API Switch exposes the standard OpenAI API specification, you can plug it into any library or tool immediately.

Python (openai SDK) 
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:3000/v1",
    api_key="sk-switch-master-key"
)

response = client.chat.completions.create(
    model="master",  # Uses your switching/fallback chain!
    messages=[{"role": "user", "content": "Hello!"}],
    stream=True
)

for chunk in response:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="")
Node.js / TypeScript 
import OpenAI from 'openai';

const openai = new OpenAI({
  baseURL: 'http://localhost:3000/v1',
  apiKey: 'sk-switch-master-key',
});

const completion = await openai.chat.completions.create({
  model: 'master', // Or 'smart', 'fast', etc.
  messages: [{ role: 'user', content: 'Explain quantum computing in 1 sentence.' }],
});

console.log(completion.choices[0].message.content);

Anthropic Python SDK 
import anthropic

client = anthropic.Anthropic(
    base_url="http://localhost:3000",
    api_key="sk-switch-master-key"
)

message = client.messages.create(
    model="master",  # Or 'claude-3-5-sonnet-20241022'
    max_tokens=1024,
    messages=[{"role": "user", "content": "Hello via Anthropic protocol!"}]
)

print(message.content[0].text)
